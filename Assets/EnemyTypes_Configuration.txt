═══════════════════════════════════════════════════════════════════════════════
                            INSTRUCTIONS UNITY
═══════════════════════════════════════════════════════════════════════════════

1. Créer le dossier:
   Assets/ScriptableObjects/EnemyTypes/

2. Pour chaque type:
   • Clic droit dans le dossier → Create → Game → EnemyType
   • Renommer selon le nom de fichier ci-dessus
   • Remplir les champs avec les valeurs ci-dessus

3. Assigner dans EnemySpawner:
   • Ouvrir le GameObject EnemySpawner dans la scène
   • Dans l'Inspector, glisser-déposer chaque asset dans les slots:
     - Scout Type      → EnemyType_Scout
     - Fighter Type    → EnemyType_Fighter
     - Bomber Type     → EnemyType_Bomber
     - Interceptor Type→ EnemyType_Interceptor
     - Assault Type    → EnemyType_Assault
     - Dreadnought Type→ EnemyType_Dreadnought

═══════════════════════════════════════════════════════════════════════════════
                         PATTERNS DE MOUVEMENT
═══════════════════════════════════════════════════════════════════════════════

Vertical        : Descente simple en ligne droite
DiagonalSoft    : Descente diagonale avec petite déviation (±20°)
VerticalZigzag  : Descente en zigzag (sin(time) * 1.5)
DiagonalFast    : Descente diagonale rapide avec grande déviation (±35°)
Sinusoidal      : Descente avec mouvement sinusoïdal ample (sin(time*2) * 3)
Circular        : Descente avec rotation circulaire complexe
