1. WEAPON UPGRADE - Amélioration d'arme (⚡)
───────────────────────────────────────────────────────────────────────────────
Nom du prefab : Collectible_WeaponUpgrade.prefab

• Type            : WeaponUpgrade
• Effet           : Augmente le niveau d'arme du joueur (6 niveaux max)
• Drop Rate Base  : 15%
• Couleur         : Jaune/Orange
• Icône suggérée  : Éclair, étoile, flèche vers le haut

Progression des armes:
  Single (0.5s)       → 1 projectile droit
  SingleFast (0.4s)   → 1 projectile droit (plus rapide)
  Double (0.4s)       → 2 projectiles à ±10°
  DoubleFast (0.3s)   → 2 projectiles à ±10° (plus rapide)
  Diagonal (0.3s)     → 2 projectiles à ±30°
  DoubleDiagonal (0.3s)→ 4 projectiles (2 à ±10°, 2 à ±30°)

═══════════════════════════════════════════════════════════════════════════════
                            INSTRUCTIONS UNITY
═══════════════════════════════════════════════════════════════════════════════

1. Créer le dossier:
   Assets/Prefabs/Collectibles/

2. Pour chaque collectible:
   
   a) Créer un GameObject vide
      • Nom : Collectible_[Type]
      • Tag : "Collectible" (créer le tag si nécessaire)
      • Layer : Default
   
   b) Ajouter les composants:
      • SpriteRenderer
        - Sprite: [Choisir un sprite approprié]
        - Sorting Layer: Default
        - Order in Layer: 5
      • Rigidbody2D
        - Body Type: Kinematic
        - Gravity Scale: 0
      • BoxCollider2D ou CircleCollider2D
        - Is Trigger: ✓ (IMPORTANT)
      • Script: Collectible
        - Collectible Type: [Sélectionner le type correspondant]
        - Move Speed: 2.0 (vitesse de descente)
   
   c) Créer le prefab
      • Glisser le GameObject dans le dossier Collectibles/
      • Supprimer l'instance de la scène

3. Assigner dans CollectibleSpawner:
   • Créer un GameObject vide "CollectibleSpawner" dans la scène
   • Ajouter le script CollectibleSpawner
   • Dans l'Inspector, glisser-déposer chaque prefab:
     - Weapon Upgrade Prefab → Collectible_WeaponUpgrade
     - Health Prefab         → Collectible_Health
     - Shield Prefab         → Collectible_Shield
     - Rapid Fire Prefab     → Collectible_RapidFire

═══════════════════════════════════════════════════════════════════════════════
                           SYSTÈME DE DROP RATES
═══════════════════════════════════════════════════════════════════════════════

Les drop rates sont DÉGRESSIFS selon la phase de jeu:

Phase 1 (0-500)       : 100% des drop rates de base
Phase 2 (500-1200)    : 90% des drop rates de base
Phase 3 (1200-2000)   : 80% des drop rates de base
Phase 4 (2000-3000)   : 70% des drop rates de base
Phase 5 (3000-4500)   : 60% des drop rates de base
Phase 6 (4500-6000)   : 50% des drop rates de base
Phase 7 (6000+)       : 40% des drop rates de base

Exemple pour Weapon Upgrade (15% base):
  - Phase 1: 15% de chance de drop
  - Phase 4: 10.5% de chance de drop (15% × 0.7)
  - Phase 7: 6% de chance de drop (15% × 0.4)

RAISON: Comme le nombre d'ennemis augmente, on compense en réduisant les drops
        pour éviter un surplus de power-ups qui rendrait le jeu trop facile.

═══════════════════════════════════════════════════════════════════════════════
                          INTÉGRATION DANS LE JEU
═══════════════════════════════════════════════════════════════════════════════

DÉCLENCHEMENT:
  Quand un ennemi meurt (Enemy.Die()), il appelle:
  CollectibleSpawner.Instance.SpawnCollectible(transform.position, enemyType)

SÉLECTION:
  Le CollectibleSpawner utilise les drop rates de l'EnemyTypeData pour:
  1. Déterminer si un collectible doit apparaître (probabilité combinée)
  2. Choisir quel type de collectible apparaît (pondéré par les rates)
  3. Appliquer le modificateur de phase (réduction progressive)

RÉCUPÉRATION:
  Quand le joueur touche un collectible (OnTriggerEnter2D):
  - WeaponUpgrade: PlayerController.UpgradeWeapon()
  - Health:        GameManager.Instance.AddLife(1)
  - Shield:        PlayerController.ActivateShield(5f)
  - RapidFire:     PlayerController.ActivateRapidFire(10f)

   • Ajouter une petite animation (rotation, pulsation)
   • Effet de particules lors de la collecte

4. PHYSICS:
   • S'assurer que les collectibles descendent à vitesse constante
   • Vérifier qu'ils se détruisent en bas de l'écran (comme dans le script)
   • Tester que le trigger fonctionne bien avec le joueur
